# Assignment 2 - Intertask Synchronization with a Ring Buffer

**Name:** Fatemeh Ghoreyshi  
**Project Name:** Assign2_Ghoreyshi_Fatemeh

## Description
- This project implements a ring buffer that is synchronized internally using FreeRTOS semaphores and mutexes.
- Multiple producer tasks periodically generate data and place it into the ring buffer.
- A single consumer task retrieves data from the ring buffer and transmits it via UART2.

## Testing
- The project was successfully built and flashed onto an STM32 Nucleo-32 Board.
- Serial communication was established through UART2 with a baud rate of 115200.
- Data generated by producer tasks was successfully retrieved by the consumer task and printed via UART.
- The test output is available in the attached screenshot file: `UART_Output.png`.

## Configuration Details
- FreeRTOS CMSIS_V2 interface used.
- UART2 configured in asynchronous mode at 115200 baud, 8-N-1 settings.
- System clock and GPIOs configured via STM32CubeMX.
- Internal synchronization managed without any delays inside ring buffer functions.
